# Desktop / Web v0.27.0

Issue #318。`feat/v27`で実装・隔離Electron検証済み。Push・PR・Releaseは未実施。

- Desktop小窓の日付上の惑星と専用の余白を削除。
- Web作業画面の上部を「作業中：タスク名」に集約。View / Current / Syncの重複表示を削除し、クリックで時間・一時停止/再開・終了・タスク詳細を開く。Escapeと外側クリックで閉じる。作業なし・一時停止も表示する。
- 左メニューの展開幅を確保し、作業詳細がメニューに隠れない配置にする。非Univのタスク詳細はこの開閉表示へ移動し、Univの選択詳細は既存オーバーレイを使う。
- Chatは会話に集中できる1列表示とし、CURRENT CONTEXT欄と3つのクイック質問はHTMLと更新処理から削除する。大きな見出しは隠す。会話欄だけスクロールし、入力欄と作業セッションは画面内に常駐する。タブ切替でも下書きは保持する。
- Three.js Univの作業中惑星は132%へ拡大し、本体の発光と減衰する周囲の光で強調する。他の未選択惑星は減光する。選択だけでは作業対象は変わらず、一時停止・終了で作業の強調を解除する。
- Univのミドルドラッグは画面に沿う平行移動。Alt+Middleも同じ操作になる。左ドラッグの回転・ホイールのズーム・右ドラッグの移動・タッチ操作は維持する。CSS表示でもミドルドラッグで移動できる。
- 天体の補間が終わると描画を停止する。reduced motion / lite modeでは最終状態へ即時反映する。
