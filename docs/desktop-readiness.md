# PETIT Desktop 完成・受入台帳

Issue: [#299](https://github.com/Soso2e/PETIT/issues/299)。実装バージョン: v0.25.0。

## 日常利用の基本構成

- 小型会話: トレイ / Ctrl・Cmd + Shift + Spaceで呼び出す。短い相談、音声、既存の確認付き操作を扱う。
- 作業画面: 小型会話の「作業画面」、またはトレイから開く。既存Universe・Tasks・Chat・Settingsを再利用する。上部の「小型会話」「Desktop設定」で戻る。
- 接続と復旧: アプリ同梱。画面取得失敗とrenderer停止を区別し、再接続または設定変更へ進む。
- Backendは従来の独立サーバー。インストーラーだけでBackend・LM Studio・STT・TTSが立ち上がる構成にはしていない。

## 自動検証と受入の境界

Desktop単体テストはURL/IPCの境界、下書き、待機中断、モニター変更時の位置復元を確認する。Electron smokeは一時profileとfixtureサーバーを使用し、所有者のDB・設定・実マイクを使わない。合成音声によるSTT・承認・TTSの配線を検証するが、実声の品質を証明しない。

Windowsパッケージの生成と同梱リソース検証は、実インストール・署名・更新の確認とは区別する。以下の実機項目を通過するまでは「デスクトップ版完成」としない。

## 後続の優先順位

全体設計・移行順の正本は [Desktop・共通Core基盤設計](desktop-foundation-design.md)（#301）。A #302 → B #303 → C #304、D #305、E #306 → F #307の依存関係に沿う。以下は領域別の残課題で、実装順を置き換えない。

1. 起動サービスの状態をまとめて表示し、Backend自動起動の運用方式を決める。別PC接続は維持する。
2. 会話/作業状態をサーバー正本へ寄せ、各画面・端末で継続する。現在は保存領域を共有しても各画面の履歴表示は独立している。
3. 音声設定の段階化、入力デバイス変更の復旧、ウェイク先頭音声引継ぎ、発話割込みを実声評価とともに進める。
4. 今日の1個、操作結果への直接移動、通知の優先度・復帰先を日常利用から評価する。Focus LoopはRefs #278。
5. 署名/公証・更新・診断情報共有・データバックアップを整え、Windows/macOSで上記受入を完了する。

UIの作り直しやフレームワーク移行を前提にしない。既存の共通トークン・動きの抑制・承認/冪等性境界を使い、実データを破棄しない。
