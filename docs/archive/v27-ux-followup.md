# v27 実操作でのUX課題

2026-10-13 JST、稼働中のWeb作業画面をCodex内ブラウザで操作して確認。Univの選択/詳細/Reset、Tasksの選択/再クリック/競合比較、Chatの入力/スクロール/切替、作業バーの開閉、統計のグラフ/記録を調査した。原因調査と修正は未実施。

## 優先して直すこと

- Tasksの「もう1回でFocusへ」という説明と動作が不一致。同じ行を2回押してもTasksに残った再現例がある。
- Univの惑星を選択して詳細を開いても、上部HUDがCoreのままでFocus/詳細ボタンが無効だった。
- タスク詳細に閲覧用の情報と編集フォームが最初から同時に出るため、閲覧中か編集中か分かりにくい。
- 作業開始ボタンが編集や親子設定の下に埋もれ、スクロールが必要。完了操作の方が先に目に入る。
- 統計をスクロールしてChat→Univへ切り替えた後、ResetしてもHUD上部が作業バーに隠れる再現例がある。

## 次に改善すること

- Univの初期表示/Resetで画面端の惑星が切れ、衛星やラベルの重なりもある。
- Tasksの期限切れと今後の期限が同じ見た目で、今取り組む対象を見つけにくい。
- 作業なしのドロップダウンは空状態や0分の情報が多く、作業開始への直接の導線がない。
- 競合比較画面で対象タスク名が見えず、採用操作の対象と結果を把握しにくい。比較の取得は確認したが、採用は実行していない。
- Chatの常設の音声方式/接続エラー案内が会話から注意をそらす。
- 統計は7日間固定で、日別の棒を押して過去日の記録へ移る導線がない。
- 統計から時間は分かるが、何を進めたかを残す振り返り欄はない。成果を確認する体験は今後の改善候補。
- 日本語とLife/Core/Focus/Yet/Now/Done等が混在し、小さく薄い補助文字も読みにくい。

## 維持したい点と検証の限界

Chatの入力欄は下部に留まり、複数行入力とタブ切替後の下書き保持を確認。統計の大きな今日の合計と内訳は取り組みを把握しやすい。

調査は1332×1244のWeb画面。実Desktop小窓、狭幅/実iPhone、音声、実LLM送信、競合採用、スクリーンリーダーはこの調査では確認していない。作業開始/終了、タスク変更、外部同期も実行していない。画面画像と詳細レポートは個人の実タスク情報を含むため、このPCのstorage/ux-audit-2026-10-13に保管し、公開リポジトリには含めない。

専属の作業相棒として、まず作業開始までの迷いと選択表示の不一致を減らす。その後、会話の継続・脱線後の復帰・成果の振り返りを、実利用で確認しながら改善する。

## 開発後の状態

Issue #321で上記の操作導線・表示・統計の日別記録と振り返り保存を改善。詳細と確認結果は [v0.28.0](desktop-v28-ux.md)。多数の天体と長いラベルの配置は完全解消とは扱わず、実端末の操作感とともに後続の受入で確認する。
