# UnivのThree.jsアニメーション

v0.27.0 / Issue #318では作業中惑星の本体・周囲の光を強調し、他の未選択惑星を減光する。ミドルドラッグは平行移動へ変更。現行の表示・検証範囲は [Desktop / Web v0.27.0](../archive/desktop-v27-experience.md) を参照。

Issue #260。`frontend/universe-webgl-scene.js`で実装する。

- 初めて描画する天体は640msで72%から本来の大きさへ現れ、発光が立ち上がる。天体間の時間差は最大175ms。
- 選択した天体は420msで114%へ拡大し、発光を強める。大気の光が一度広がり、通常の大気サイズへ戻る。
- 選択解除は現在の大きさ・発光から元へ戻る。連続選択では途中の値から次の動きへつなぐ。
- 既存のFocusカメラ移動、ドラッグ操作、クリック判定は維持する。通常のデータ再描画では既出天体の登場演出を繰り返さない。
- 常時ループは追加しない。カメラと天体の動きが終わると描画を停止し、非表示画面・非表示タブでも停止する。
- OSのreduced motionと軽量モードでは天体の動きを省略する。reduced motionを途中で有効にした場合も最終状態へ移る。

Windows Edgeで実Three.js/WebGLとテスト用タスクを使い、登場、選択の中間値・最終値、連続選択、reduced motion、描画停止を確認。実データを使った大量天体・実iPhone/macOSの性能は未確認。Desktop小型会話画面にはThree.js空間はなく、これはWebのUnivに対する変更。


## タスク状態更新時の遷移

Issue #279。タスク完了などでUniverseのデータが更新される場合も、シーン全体を瞬間的に切り替えない。

- 完了APIが成功した天体は、280msで縮小・減光してから新しいタスク一覧へ更新する。
- 再構築後も残る天体は、更新前のワールド座標を保存し、520msで新しいレイアウト位置へ補間する。
- 新しく追加された天体は既存の登場アニメーションをそのまま利用する。
- 補間中だけ `requestAnimationFrame` を継続し、完了後は描画を停止する。常時レンダーループは追加しない。
- `prefers-reduced-motion` または軽量モードでは退出・位置補間を即時反映する。
- Web/PWAのThree.js Univが対象。Desktop小型会話UIにはThree.jsシーンがないため、Web UIを表示する導線でのみ同じ挙動になる。

## タッチ・ドラッグ操作と選択の分離

Issue #323、#393。スマートフォンや狭い画面で星や名前ラベルが密集している場合でも、自然にカメラを操作できるよう操作体系を統一する。

カメラ入力は `universe-webgl-scene.js` の `createCameraController`（自前実装）が担う。v0.46.0でOrbitControlsから置き換えた。OrbitControlsはdocument全体のtouch `pointermove` を追跡外の指まで回転入力に使うため、2本目の指がHUDに乗ると回転が2本の指の位置を往復していた（「ガガガ」）。

- 1本指・左ドラッグ: 回転。2本指: ピンチで拡大縮小しつつ中点で平行移動。右・中・Shift+ドラッグ: 平行移動。ホイール・トラックパッドのピンチ（ctrl+wheel、Safariのgesture event）: カーソル位置へ拡大縮小。
- ジェスチャーに属する指（Canvasで始まった指と、操作中に追加された指）だけがカメラを動かす。操作中に2本目の指がHUD・ナビ・ラベルに乗った場合も、その指はジェスチャーに参加し、ボタンは押されない。
- ピンチの後に1本だけ指が残った場合、全ての指が離れるまでその指ではカメラを動かさない（ピンチの終わりが急な回転にならない）。
- 指の本数が変わるたびに基準点を取り直すため、カメラが飛ばない。
- ドラッグ中は軽い追従スムージングだけを入れ、素早く弾いて離した時だけ短く慣性で流れる（最大でも約55°）。止めてから離した場合は流れない。速度は入力イベント自身のタイムスタンプで計算する。
- タップ判定もカメラ入力側で行う。1本の指だけで、移動量が閾値（touch: 10px, pen: 8px, mouse: 5px）未満、550ms以内に離した場合だけ `tap` とし、2本指が一度でも触れた操作は選択にならない。
- タップ時の当たり判定: ①はっきり見えている名前ラベル（不透明度0.5以上か選択中）の文字の範囲（周囲touch 6px / mouse 2px）②天体メッシュのRaycast ③touchのみ、画面上の半径が16px未満の小さい天体を中心から16px以内で拾う。ラベルの枠（暗くほぼ見えない部分）や、遠くて薄いラベルは当たりにならない。
- WebGL表示中は、データとアクションの橋渡しに残している旧DOM（`#constellation-grid`）の子孫も全て `pointer-events: none` にする。`univ-space.css` が旧ボタンに `pointer-events: auto` を付けていたため、見えない旧ボタンがスマホで3Dビューの約15%を覆い、そこから始めたドラッグが効かない・何もない所のタップで近くのタスクが選択される原因になっていた。
- DOM名前ラベルの `pointer-events` は `none` のまま。キーボード操作（Tab移動、Enter/Spaceでの選択）は維持する。
- マウス移動時はラベルおよび天体上でカーソルを `pointer` とし、ラベルへ `.is-hovered` を付与する。
