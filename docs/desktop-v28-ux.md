# Desktop / Web v0.28.0：作業開始と振り返り

Issue #321。v27の[実操作UX調査](v27-ux-followup.md)をもとに、`fix/v27-ux-followup`からmain向けに提供。CIとマージ状態は関連PRを正とし、配布版の更新・受入は別途。

## 操作の変更

- Tasksは1回で選択、同じ行をもう1回押すと選択した惑星と詳細を開く。Enter/Spaceでも操作でき、行内の完了ボタンの操作とは分離する。WebGLの選択とHUDの対象・操作可否を同期する。
- 詳細はまず閲覧のみ。編集を押してフォームと親設定を開き、キャンセルで閲覧へ戻る。作業開始と相談はタイトルの直下。子タスクの追加は折りたたむ。閉じるボタンと編集の重なりも修正。
- Univの全体/リセットは惑星・衛星の位置と画面比率から視点を決める。作業バー/HUDの余白を確保し、遠景の霧を調整。重なる未選択の衛星ラベルを控え、選択・作業対象のラベルを優先する。補間終了後の描画停止とreduced motionは維持。
- 切替時のページスクロールを解除しHUDを固定する。統計などの操作が固定バーに隠れないようスクロールの余白を設ける。
- 期限はJSTで期限切れ・今日・3日以内を文字で区別。作業なしのドロップダウンはタスク選択へ進むボタンに集約。競合比較は対象名と両方の採用結果を明示する。
- Chatの通常の音声方式説明は音声設定の中へ移動。録音・認識失敗などの状態表示は維持する。状態・優先度・エリアなどは値を変えず日本語で表示。
- 統計の日付入力、7日間の棒、今日に戻るボタンで日別内訳と記録を選べる。過去日を現在時刻と分けてCoreで集計し、休憩・日跨ぎの既存計算を共用する。
- 「できたことを残そう」で日付別の振り返りを明示保存。入力は日付/タブ切替・定期更新・保存失敗でもこの画面に保持する。ページを離れる際は未保存を確認する。別の画面との保存競合は上書きせず、入力を残して保存済みの再読込を案内する。
- Desktopの同一文書内のタブ切替でready状態を失い、8秒後に復旧画面へ戻る問題を修正。再読込や新しい文書・renderer停止に対する復旧は維持。

## APIと保存

- `GET /api/work-sessions/days/{YYYY-MM-DD}`：指定したJST暦日の集計と振り返り。今日の既存APIにも`reflection`を追加。
- `PUT /api/work-sessions/days/{YYYY-MM-DD}/reflection`：`note`（最大2000文字）と取得時の`revision`を送る。保存成功でrevisionを増やす。古いrevisionは409。未来日/不正日付/過長入力は422。
- SQLiteへ`work_day_reflections`を追加。既存の作業記録は維持し、明示保存した日付のメモだけ更新。取得時点のrevision比較と更新は同じSQLiteトランザクションで行う。
- 振り返りはこの画面の手動記録。会話やRAG・外部同期へ自動配信しない。未保存の入力は画面のメモリ内で保持し、アプリ終了後の復元は行わない。
