# 音声タスク操作と省トークン化

## 変更内容

- Chat / Agentの常時プロンプトを短縮し、Markdownを禁止
- AIルーターから`update_task`、`get_task_sync_status`、`retry_task_sync`を選択可能に変更
- 「締切を延ばして」「日付を変えて」などを`update_task`へ直接ルーティング
- タスク編集時に不要な`get_tasks`ツール定義を同時に渡さない
- 読み上げ対象を返答本文のテキストノードだけに限定
- 確認待ち中の「はい・実行して」「キャンセル」などを音声で承認・拒否
- 書き込み成功後のJSON表示・読み上げを短い自然文へ変換

## 安全性

音声承認は、画面上に有効な確認ボタンが存在し、発話が登録済みの短い承認・拒否表現と一致した場合だけ実行する。曖昧な発話は通常のチャットとして送信する。

## 実機確認

1. 音声応答をONにする
2. 「ポスターのタスクの期限を変更して」と話す
3. 確認表示後に「はい」または「実行して」と話す
4. 画面と読み上げが「タスクを変更しました。」になることを確認する
5. 別の操作で「キャンセル」と話し、書き込みされないことを確認する
6. 詳細欄、ツール名、処理時間が読み上げられないことを確認する
